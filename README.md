# 💻 Exercícios de Lógica com JavaScript

## 📌 Descrição

Este repositório reúne uma série de exercícios desenvolvidos em JavaScript com foco em lógica de programação, utilizando principalmente estruturas de repetição (`while`) e validação de dados de entrada.

Os exercícios simulam situações comuns do dia a dia, exigindo controle de fluxo, tratamento de erros e interação com o usuário.

---

## 🧠 Objetivos dos exercícios

Os problemas propostos abordam os seguintes cenários:

* ✔️ Validação de número positivo digitado pelo usuário
* ✔️ Cálculo de média com quantidade indefinida de valores
* ✔️ Soma de valores até uma condição de parada
* ✔️ Verificação de campos obrigatórios (nome e sobrenome)
* ✔️ Simulação de saque com validação de saldo

---

## 🚨 Principais desafios encontrados

Durante o desenvolvimento, alguns pontos exigiram maior atenção:

### 🔁 Controle de repetição

Foi necessário garantir que os loops só fossem encerrados quando as condições corretas fossem atendidas, evitando loops infinitos.

### 📍 Validação de dados

Os dados inseridos pelo usuário precisaram ser validados continuamente, garantindo que valores inválidos fossem rejeitados.

### ⚠️ Uso de condições lógicas

A construção correta de condições com operadores (`||`, `&&`) foi essencial para o funcionamento esperado dos programas.

### 🧱 Organização do código

Manter a estrutura dos blocos com `{}` e posicionar corretamente as validações dentro dos loops foi fundamental para evitar erros.

---

## ✅ Soluções aplicadas

Para resolver os problemas, foram utilizadas as seguintes abordagens:

* Uso de `while` para repetição até condição válida
* Implementação de validações dentro dos loops
* Atualização correta de variáveis de controle
* Separação lógica entre entrada, validação e processamento

---

## 🧠 Aprendizados

* Estruturas de repetição com `while`
* Validação de entrada de dados
* Controle de fluxo em programas interativos
* Prevenção de loops infinitos
* Escrita de código mais organizado e legível
